# Islamic Talk Dubbing Studio

Dub Arabic Islamic talks on your own PC, in the speaker’s own voice, with human review.

**[Request your Studio download on DeenDub →](https://deendub.com/#/local-studio)**

This is the public home of the project: discover Studio, report problems and propose contributions.
The application code and development history are maintained privately. Downloading this repository gives
only this showcase, not the Studio application.

## Get Studio

1. Visit **[deendub.com/#/local-studio](https://deendub.com/#/local-studio)** and sign in.
2. Send a download request. Manaf reviews requests personally and can approve or decline them.
3. Return to the same page. Once approved, download and extract the Studio ZIP.
4. Follow the included setup guide, or open the folder in your AI coding assistant and ask it to follow
   `SETUP_FOR_AI_AGENT.md`.

Download approval does not grant GitHub collaborator access. Updates are available from the same DeenDub page
while your download access is approved. The approved application includes the Python files it needs to run.

## What Studio does

- Transcribe Arabic talks and compare independent transcripts.
- Proofread and translate with human review before sharing.
- Dub in the speaker’s voice using local AI or your own supported API services.
- Preserve Quran recitation, du'a and dhikr in the original audio.
- Review timing and wording, then export video, audio and subtitles.
- Choose multiple output languages, original background sound and subtitle options.

Local models need suitable hardware. The included setup guide checks your PC and helps choose a configuration.
AI output needs a human review, especially religious quotations, names, negations and rulings.
